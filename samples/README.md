# Sample recordings for the optional GitHub Actions CPU workflow

The optional Actions workflow uses the upstream example voice by default, so this
folder can remain empty. To use your own WAV, you'd need to commit it here and
select `repo-wav` when running the workflow.

**WARNING: Do not commit a private voice recording to a public repository!**
Git commits persist in history even after a file is deleted. Use a private
repository for any sensitive samples, or the separately deployed authenticated
cloning API instead. Only clone a consenting speaker's voice.
